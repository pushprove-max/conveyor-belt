# 1.5.0

This release stops cards from running the whole test suite, adds benchmarks, and makes the Board show each card's real step.

## Tests

- A card no longer runs the whole test suite. A card runs each of its test files alone, in every case. The whole suite runs on main, in a release or with `conveyor.sh full-test`.
- When a card has no short list of tests, it runs the test files the test map links to its change, at most 50. The files that failed most recently run first, and the card says how many it left for the release.
- A card stops a test command that runs far more test files than it was given, and says which setting fixes it.
- Doctor and setup now warn when the test command ignores the files it is given, and suggest `test.fileCommand`.
- A card's own test failures no longer mark main as broken. Conveyor first runs the failed files on main alone.
- When a main fix finds nothing to fix and the files pass on main, the broken mark is cleared.
- A test file that the test map cannot run no longer stops the whole map. The map lists it as not mapped, with the reason.

## Models

- The Board offers the models that the installed Codex reports, so a new model shows up without a manual edit.
- A model with no price shows as having no price, and one held issue is filed to add it. Only models that Conveyor runs or offers get an issue.
- The Board has prices for gpt-6.2-sol and gpt-6.2-astra.

## The Board and /units

- A card shows the step it is in now, with that step's own timer. A card in its fix step no longer shows as testing.
- A bug card's check that its new tests fail without the fix shows as its own step, "Proof run", with its file count.
- Queue and Queue all now take on the first press.
- The held list shows an area's name without the colon of its label.
- /units uses the full width of its pane, and no longer falls back to a narrow layout.
- /units shows the cap in the On the belt heading, and shows the machine line only when the machine holds cards back.
- An idle refresh no longer closes the open Group by menu in the Rules tab.
- The Board shows why the usage guard refused Start.

## Benchmarks

- Run SWE-bench Verified through Conveyor with any number of tasks, or the presets 1, 5, 20 and 50. Older versions of Conveyor can be compared.
- The drift watch compares cards before and after an engine change: tokens, minutes, reviews, blocks and waits.

## Doctor and status

- Doctor no longer reports a proxy key as missing when a call through the proxy works. When a key is needed and missing, doctor says how to fix it.
- Setup and doctor show progress during the slow route checks.
- `foreman status` says when the snapshot is being made after a resume, and no longer prints an empty "()".
- A damaged card record no longer stops the snapshot.

## Releases

- The owner can release past named commits that are already pushed, with `release --allow-commit`.
- A test that failed only under the release suite's load is fixed.
