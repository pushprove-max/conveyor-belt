# 1.1.1

This release makes panel widths easier to change on the Board, gives every Tests page action a visible progress indicator with its result shown in place, and fixes installing the plugin on machines without a GitHub SSH key.

## The Board

- Each panel's header now has a width control beside the up, down, and collapse buttons, so you can change a panel's width without opening Customize. It works with the keyboard and on a phone.
- Customize no longer has a width setting. It still handles showing and hiding panels, density, theme, and restoring the layout.
- The Release panel now offers Small, Wide, and Full widths and starts at Small.
- At Small width, each releasing project's card stacks its three steps and its next button in one narrow column.

## Tests

- Clicking Judge on a file now starts the judge, and the page shows right away beside the button that it has started.
- Every Tests page action, including Judge, Optimize, Run, Mutation check, and Explain the slowdown, shows a progress indicator from the click until it finishes. The indicator shows whether the action is queued (and how many are ahead of it), running (with elapsed time), or done.
- When an action finishes, its result appears in the same place you clicked: the file's row or the selected-files bar. A judge's verdict and report, and a run's pass or fail, show there.
- If an action fails or cannot start, such as when no Tests model is set, the page now says why in the same place.

## Setup

- Installing Conveyor with `/plugin install conveyor-belt@conveyor-belt` now works on a machine with no GitHub SSH key. Previously it failed with a "Permission denied (publickey)" error.
- The install commands are now shown as a code block, ready to copy.
