# 1.5.1

This release removes the machine room, so no card or test waits for the machine's load, pressure or free memory.

## Cards and tests

- The machine room is removed. No new card waits for the machine's load, pressure, wake delay or free memory, and no test waits for them to take a free test slot. Each project's cap, the machine's cap, its pause and the test slots are the only limits.
- On macOS, cards no longer wait on an idle machine because a short sleep woke late.
- The host file settings `maxLoad`, `minFreeMemMB` and `pressure` no longer do anything. Doctor says so once when the host file still sets them.
- The `machine load` command is removed.

## The Board and /units

- Health no longer has a Machine room row, and the queue no longer says "waiting for machine room".
- The Tests page no longer has a Load limit.
- /units no longer shows a machine line under On the belt.
