# 1.4.0

This release makes the Tests page and the Board far easier to act on, makes the Foreman recover on its own more often, and speeds up Conveyor's own work.

## Tests

- Each test file on the Tests page now opens with a short summary: its state, how far over budget it is, the latest judge verdict, and one suggested next step.
- Run history is shown as a small trend chart rather than sentences, with exact values on hover.
- Each optimization shows as before and after, with a percentage and a clear note on whether it helped.
- Test edits show their issue number and time, not internal card IDs.
- The judge's full report is folded under its one-line verdict and opens on demand.
- The judge now receives each file's recorded runs and timings, so it no longer says a file has no history when it does.
- Failures caused by a change are now shown as caught changes and no longer count toward "Fails often".
- Each problem status on the Tests page now has a fix action: Fails often, Hollow cases, Waiting, Never run, Wall time only, and Runs other test files.
- Build the test map by hand from the Tests page, with a progress bar and a Stop button.
- Test history is no longer cut off after five runs per file.
- The Board's Rules tab keeps a queued or held issue shown as moved until a fresh update confirms the change, and brings it back with an error if the change fails.
- The Tests page header no longer covers the content of an open row.

## Setup

- A proxy that needs no key now works without asking for a sign-in.
- Setup and the Foreman now ask before committing the Conveyor pack, and commit only that file on yes.
- Setup and install-service now restart the running service on the new version, so it stops refusing a newer project file.
- Setup reports when a project's Conveyor runs on a build machine, and no longer offers a second service there.
- Setup now says when the Board's certificate has been made again.
- A fresh install now opens the Board on the first start, including on macOS with its built-in OpenSSL.
- The Board makes its certificate again when the file is missing or damaged, instead of crashing on every start.
- You can reserve cores for yourself, so Conveyor's test runs and card sessions leave them free.

## The Board and /units

- The test map's progress and state show in /units, and the line now fits narrow terminals.
- /units no longer writes anything to your machine when it reads.
- The Board's Health tab can show what is busy on the machine, grouped by card, with a responsiveness measure.
- The Board's Belt panel now counts only building cards against the cap, matching the status line.
- The Foreman's watcher restarts by itself, so it keeps listening during a long turn and after a crash.
- The Foreman wakes you when a card has waited ten minutes, and it tries to fix the cause before reporting.
- The Foreman's "unreachable" alerts no longer fire when the machine is only slow under heavy load.
- A card that waits on another card no longer takes a build slot.
- A card that changes the same files as another card is now stacked on it instead of waiting, and lands first once it has passed review and tests while the other card is in a fix round.

## Cards and tests

- A card that changes only one file can be checked on a faster test path, and a split test file is judged fairly against its budget.
- A test file that cannot fit its budget now stops and asks you for its own budget, instead of being blocked again and again.
- Cards blocked by the old speed check are retried automatically once the check is fixed.
- A red main is now proved by its failing cases passing, not by new tests.
- A test run that is cut off by a restart is no longer reported as a failure on main, so cards stop waiting on a false red main.
- A failure is now judged as the machine's when the control check passes, and cards pause rather than opening a red main card.
- Each engine test file runs and is reported on its own, so a broken setup in one file no longer fails unrelated files.
- Engine tests no longer collide over shared release and full-test locks, so cards can test side by side.
- A speed-up or optimization card whose build proposes its own budget now stops for your yes instead of being blocked.

## Engine

- Conveyor starts far fewer helper programs on its hot paths, so a snapshot is quicker.
- Conveyor keeps the failure output of its background updates, and names a stale engine on the Board and in doctor.
- Conveyor no longer removes a version that another project on the machine still uses.
- Conveyor keeps its background updates current and repairs a missing version when it is needed.
- The service no longer keeps old copies of its output after restarts, which had caused false test failures.
- Automatic decisions cover routine kinds you turn on in the Rules tab, and they are logged.
- A full test run that dies no longer blocks later runs.
- A release test run now stops a test case that runs past its time limit, names it as timed out, and goes on, instead of stalling with no error.
- Cards that wait on or stack on another card behave as the batch and give-way tests expect again.
- The auto-off message counts only decisions made, not entries still waiting for you.
- The Foreman's stop check no longer rejects a reply to your request during a wake.
