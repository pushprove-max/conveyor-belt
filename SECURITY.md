# Security policy

## Reporting a vulnerability

Report a vulnerability privately, through GitHub's private vulnerability reporting for this repository: on the
repository's **Security** tab, select **Report a vulnerability**. Do not open a public issue, pull request or
discussion for it. The report stays private between you and the maintainers until a fix is out.

## Supported versions

Only the newest release gets security fixes. A fix comes out as a new release; to get it, update the plugin
(`/plugin marketplace update conveyor-belt`, README.md, Install).

## What to include

- What an attacker can do, and what they need first (access to the machine, to the repository, to an issue).
- The steps that show it, as short as you can make them.
- The Conveyor version: the commit `conveyor doctor` names, or the release you installed.
- Your Claude Code version and your operating system.
- The log lines that show it. Remove private words first: names, email addresses, host names, paths in your home
  folder, tokens and keys.
